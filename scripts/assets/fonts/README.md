# PDF font inputs

TTF equivalents of the two locally hosted site font families, downloaded 2026-11-02 from Google Fonts. They use the SIL Open Font License 1.1; the unmodified licenses are at `public/fonts/Barlow-OFL.txt` and `public/fonts/Barlow-Condensed-OFL.txt`.

- `barlow-regular.ttf`: https://fonts.gstatic.com/s/barlow/v13/7cHpv4kjgoGqM7EPCw.ttf
- `barlow-semibold.ttf`: https://fonts.gstatic.com/s/barlow/v13/7cHqv4kjgoGqM7E30-8c4A.ttf
- `barlow-condensed-extrabold-italic.ttf`: https://fonts.gstatic.com/s/barlowcondensed/v13/HTxyL3I-JCGChYJ8VI-L6OO_au7B6xTrf3fWvA.ttf

These authoring files are not copied to the static website. The public PDF embeds subsets.
