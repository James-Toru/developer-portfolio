# Local font licenses and source

Two font families are served locally. Both are by Jeremy Tribby and distributed under the SIL Open Font License 1.1. The complete licenses are retained beside these files. No third-party font request occurs at runtime.

Downloaded 2026-11-02 from the Fontsource distribution of the Google Fonts Barlow project:

| Local subset | Original URL | Weight/style |
| --- | --- | --- |
| barlow-400-latin.woff2 | https://cdn.jsdelivr.net/npm/@fontsource/barlow/files/barlow-latin-400-normal.woff2 | 400 normal |
| barlow-600-latin.woff2 | https://cdn.jsdelivr.net/npm/@fontsource/barlow/files/barlow-latin-600-normal.woff2 | 600 normal |
| barlow-condensed-800-italic-latin.woff2 | https://cdn.jsdelivr.net/npm/@fontsource/barlow-condensed/files/barlow-condensed-latin-800-italic.woff2 | 800 italic |

These are Latin subsets. The local committed files, rather than a moving remote URL, are the build inputs. Fontsource's supplied subset names are preserved in this source record; internal font names are unchanged. License sources: https://github.com/google/fonts/blob/main/ofl/barlow/OFL.txt and https://github.com/google/fonts/blob/main/ofl/barlowcondensed/OFL.txt.
